# All-India company-master index snapshot

Data-only branch; the website code is on main. Source: https://github.com/kk9234282-art/one-sun/releases/download/india-data-v1/company_master_data_2026-10-31.zip

3,236,908 unique structurally valid company CINs; 56 exception rows retained separately. Counts describe the supplied release, not a certified national census. Original states are retained in profile data; current state aliases are documented in source-report.json. No company financial statements were supplied.

Archive SHA-256: b6dfedff66c92f5eeff0caf5ea0b493c3cba00f6695413bd6a1c1b80fe0979dc

Compressed index/profile files are immutable and individually checksummed by the catalog on main. User accounts, passwords, database files, local ZIP uploads, session keys and backups are not included. The data was explicitly authorised for public sharing by the repository owner. Provider usage limits still apply.
