# Postal data attribution

The bundled PIN/district reference is reduced from the JSON data in **india-pincode 2.5.9**, authored by **Deepak Kumar** and distributed under MIT according to its package manifest.

Source: https://registry.npmjs.org/india-pincode/-/india-pincode-2.5.9.tgz

The package's underlying postal record date is unspecified. We retain distinct district labels per state/PIN and withhold conflicting pairs; no majority vote or company-address inference is used. Package integrity and data hashes are included in `intelligence/static/pin-districts.json` and generated by `scripts/build_pin_reference.py`.

## City / postal-area reference

`india-pincode-search@1.0.2`, Mayank Jhawar: https://registry.npmjs.org/india-pincode-search/-/india-pincode-search-1.0.2.tgz

Its package manifest specifies ISC; its README states MIT. The village field is retained as a representative postal-area label only when all rows for the same state/PIN agree and the primary district mapping is known. The source's `city` and `district` field names are not treated as municipal boundaries. Package published 2023-03-01; underlying record date unspecified. Source hashes are in the bundled reference.
